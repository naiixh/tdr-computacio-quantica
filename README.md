# Computació Quàntica
 
Treball de Recerca de Batxillerat sobre **computació quàntica** (2022).
 
## Resum
 
Estudi de la computació quàntica i de la seva repercussió actual i futura, des dels qúbits fins a tecnologies com la criptografia quàntica.
